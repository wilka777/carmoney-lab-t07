## Договорённости

- Ветки называем `d<день>/<модуль>-<логин>`; прямые изменения в `main` не
  делаем, работа сдаётся через PR.
- По умолчанию: MiniMax M3 для кода и частых прогонов, GLM 5.3 для анализа,
  планов и интервью.
- Каждый участник использует личный ключ OpenRouter и проверяет остаток перед
  началом дня 2; общий остаток не фиксируется.
